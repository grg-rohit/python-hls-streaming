🏠 Local network

  1. Connect phone to the same Wi-Fi.
  2. Find laptop IP: ipconfig (Windows) / ip addr (Linux/macOS)
  3. Open: http://<LAPTOP_IP>:8000
  4. If unreachable, allow port 8000 in your firewall.

🌐 ngrok public URL

  1. Install & auth ngrok: ngrok.com
  2. Run: ngrok http 8000
  3. Copy the https://….ngrok.io URL.
  4. Open on any device.
